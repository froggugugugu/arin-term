## レビューと照合で見つけて直したもの(各 1 回。コミット `367c281`)

| 重さ | 内容 |
| ---- | ---- |
| MUST | 外の変更の読み直しが保存・打鍵と競合すると、未保存の印と版が失われる → `check_document` は状態を変えず、画面が本文を当てたあとにだけ `adopt_document` で版を持ち直す |
| MUST | 「作る」が、確認のあとにできた同じ名前のファイルを置き換える → `create` は `RENAME_EXCL` で、あれば `changed-outside` |
| SHOULD | 保存で Rust が未保存の印を消す(保存のあいだの打鍵が印から漏れる) → 印は画面だけが送る |
| SHOULD | 改行が混ざった文書の比べる基準が保存と食い違う → 中では `\n` で持ち、保存で文書の改行に戻す |
| SHOULD | 親フォルダが無いとき「作る」の確認が繰り返される |
| SHOULD | 自分の保存の改名を外の変更と取り違える → 保存中は確かめを飛ばし、終わってから 1 回 |
| SHOULD | 衝突の確認の「読み直す」で、打った分が残る → 外の版が同じでも本文を受け取って当てる(`always`) |
| SHOULD | 画像の入れ子が 32 段の打ち切りから漏れる |

## 判断が要る点・残っている問題

| 項目 | 状態 |
| ---- | ---- |
| 一時ファイル `.arin-save-*` | 書きかけで外の変更を見つけて止めたとき、一時ファイルが残る(削除の経路を作らない規則のため)。標準エラーの `[arin:editor]` に場所が出る。消す経路を作るかは本人の判断 |
| 版の比べ方 | stat の 4 つ(`dev`・`ino`・`size`・`mtime_ns`)が同じなら中身を比べない。大きさと mtime を保って書き換える道具の変更は見落としうる |
| IME | 変換中の ⌘S でも保存が走る |
| 本物の `CodeMirrorEngine.ts` | 単体テストが無い(Vitest に DOM が無い)。E2E だけで確かめている |
| 「読み直す」 | 取り消しの履歴が消える |
| アプリ内の改名・ゴミ箱 | エディタのタブが追従しない。保存すると「消えていた → 作る」の確認になる(ADR の 3 のとおり) |
| 「パスをターミナルに挿入」 | エディタを出しているあいだは、隠れている表示中のターミナルが宛先になる |
| 設定画面 | 画面の文字 18 のとき、高さ 600 では縦にスクロールする(Vim の行が増えたため) |
| プレビュー | 画像を読み込まない・リンクを開かない(方針どおり)。編集とプレビューのスクロールを合わせない。リンクの参照(`[a][r]`)は URL を解決しない |
| バンドル | エディタの塊が見込みより大きい(上) |
| 【要確認】1 | タイル表示で開くとタブ表示に替わる(A で実装) |
| 【要確認】2 | 再起動で開き直さない(A で実装) |
| 【要確認】3 | PRD の N1・N7 への反映(未。了承まで書き換えない) |

## 本人に確かめてほしいこと

`npm run app:debug` の `.app` の中の実行ファイルを端末から起動し、標準エラーを見ながら:

1. ツリーから `.md` を開くとエディタのタブが出る。同じファイルは同じタブ。ほかのファイルと右クリックの「既定のアプリで開く」は今までどおり(AC-E01)
2. 「編集」「並べて」「プレビュー」の見た目。生の HTML・画像・リンクの扱い。ライト・ダーク・すりガラスの上で読める(AC-E03・E15)
3. ⌘S で保存し、Finder のタグと権限が残る。ほかのエディタで書き換えてから保存すると聞かれる。消してから保存すると「作る」を聞かれる(AC-E04・E05)
4. ほかのエディタで書き換えると読み直される。未保存なら帯が出る。ほかのプロジェクトの文書はタブを戻したとき・ウィンドウを前面に戻したときに確かめる(AC-E06)
5. 未保存で ⌘W・×・終了・プロジェクトを外すと聞かれる(AC-E07)
6. 設定画面で Vim を切り替え、`:w`・Esc が効く。エディタの上で ⌘W・⌘T・⌘,・⌘1〜9 がメニューに届き、⌘A・⌘C・⌘V・⌘X・⌘Z がエディタの中で効く(AC-E08・E09)
7. 文字の大きさの「ターミナルとエディタ」を変えるとエディタとプレビューの本文が追従する(AC-E10)
8. エディタを開いたあとも端末に `[arin:frontend-error]`(CSP の違反)が出ない(AC-E13)
9. ADR-015 の【要確認】1〜3 の回答と、上の「判断が要る点」の扱い(一時ファイル・IME・バンドルの大きさなど)

## 誰も確かめていないこと

- 本物の CSP の下でエディタを開くこと(スモークはエディタを開かない。E2E は Vite の画面で CSP が当たらない)
- メニュー経由の ⌘W・⌘A・⌘C・⌘V・⌘Z が本物の CodeMirror に届くこと
- ウィンドウが前面に戻ったときの確かめ(実機)
- 本物の Vim の部品の操作感と `:w`
- ライト・ダーク・すりガラスの上の実機の見た目
- 1 MiB の文書の開く・解析の時間とメモリ(`npm run perf` を回していない)
- 本物の Finder のタグ・ACL が保存で残ること(テストは一時フォルダで試験用の拡張属性を確かめた。`crates/arin-platform/tests/document.rs`)
