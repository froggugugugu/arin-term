## 本人に確かめてほしいこと(T73a の (1)〜(9))

`npm run app` で作った `target/aarch64-apple-darwin/release/bundle/macos/Arin.app` を Finder から開く。

1. ⌘, とアプリ名のメニューの「設定…」で設定画面が開く(AC-F01)
2. タブ表示とタイル 9 枚でターミナルの大きさを変えると、すぐ変わり、Claude Code などが続いて描き直される。続けて押しても固まらない(AC-F02)
3. ほかのタブ・ほかのプロジェクトに切り替えても新しい大きさ(AC-F03)
4. 画面の大きさを変えると、サイドバー・タブ・ツリー・右クリックのメニューの文字と行がそろって変わり、線とアイコンはにじまない(AC-F04・F05)
5. 再起動しても残る。「既定に戻す」で M4.5 と同じ見た目に戻る(AC-F07〜F09)
6. 「設定ファイルを開く…」(設定画面のボタンとメニューの項目)が M4.5 と同じに開く(AC-F10)
7. キーボードだけで操作できる(↑↓・Home・End・Tab・Esc・Return)。設定画面を開いたまま ⌘W で設定画面だけが閉じ、タブは閉じない(AC-F12)
8. 見た目(ライト・ダーク・すりガラスの上)(AC-F13)
9. ADR-013 の【要確認】3〜5 の回答、PRD への反映、M5 の依存を T73b に替えるか
