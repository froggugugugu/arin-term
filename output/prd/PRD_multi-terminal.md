## 1. 概要

### 1.1 背景・目的

- 現状は VSCode をプロジェクトごとに複数起動し、その統合ターミナルで Claude Code / Codex を動かしている。エディタ機能はほぼ使っておらず、メモリだけ消費している(REQ §2)。
- 一方で VSCode の「ファイル構成が見える」「ファイルパスを取得できる」は手放したくない。cmux は機能が多すぎ、tmux はツリーがない(REQ §2)。
- 目的: **VSCode から「エクスプローラ+ターミナル」だけを抜き出し、マルチプロジェクト化した macOS ネイティブアプリ**を作る。エディタは持たない(REQ §1)。

ゴール(REQ §3):

| ID | ゴール |
| -- | ------ |
| G1 | 1 ウィンドウで複数プロジェクトを切り替えて作業できる |
| G2 | 左ペインのツリーと右ペインのターミナルが常に同じプロジェクトを指す(タイル表示ではフォーカス中のタイルのプロジェクト)。対応関係はプロジェクト色で一目で分かる |
| G3 | ツリーからファイルパスを最短手数でターミナル(=AI エージェントへの入力)に渡せる |
| G4 | VSCode 複数起動より明確に軽い(§4 の数値は目安で、合否判定には使わない。今後の機能拡張では軽さの優先度を下げてよい。2026-11-14 本人回答) |
| G5 | Apple 公証済みの .app として自分の Mac に入れられる |

利用者は本人のみ。代表シーンは「朝の立ち上げ」「並行作業」「ファイルを指示に含める」「構成の確認」の 4 つ(REQ §4)。

## 2. 用語定義

| 用語 | 定義 |
| ---- | ---- |
| プロジェクト | ユーザーが登録した 1 つのルートフォルダ。カード 1 枚=プロジェクト 1 つ=ルートフォルダ 1 つ。git リポジトリである必要はない(REQ §4.1) |
| ルートフォルダ | プロジェクトの起点フォルダ。1 プロジェクトに 1 つだけ。Arin はこの中に設定ファイルを書き込まない |
| カード | 左ペイン上段に並ぶ、プロジェクト 1 件を表す表示単位 |
| ツリー | 左ペイン下段の、選択中プロジェクトのファイル/フォルダ階層表示 |
| ターミナル | 1 つのシェルプロセスとその表示。所属プロジェクトは「どのプロジェクトで開いたか」で決まり、`cd` で外へ出ても変わらない |
| タブ表示 | 選択中プロジェクトのターミナルを横タブで並べ、1 枚ずつ表示する右ペインのモード |
| タイル表示 | ターミナルを自動グリッドで同時表示する右ペインのモード。1 ページ最大 9 枚 |
| ページ | タイル表示で 1 画面に収まるタイルの集合 |
| プロジェクト色 | プロジェクトごとに持つ淡い色。カードとタブ/タイルのタイトルを同じ色で着色する |
| アテンション | 非表示のプロジェクト/タブがベル(BEL)または通知シーケンス(OSC 9/777)を出したことを示すバッジ |
| 実行中の印 | プロジェクトのいずれかのターミナルで、シェル以外のプロセスが前面で動いている間だけカードに出す印 |
| 最近変更の目印 | ファイル監視で検知した追加・変更に付け、時間とともに薄れて消える印 |
| 再リンク | 「見つからない」状態のプロジェクトに、ルートフォルダを指定し直す操作 |
| 相対パス | プロジェクトのルートフォルダを基準としたパス |
| 人間ゲート | AI に任せず人間が実行・判定する事項(秘密情報の取り扱い、実機の体感確認、非ゴールの変更) |
| 【要確認】 | ユーザー判断が必要な曖昧箇所。選択肢を併記する |

### 3.1 プロジェクト管理

ユーザーストーリー: 本人が、複数プロジェクトを 1 ウィンドウに登録して切り替えたい。VSCode をプロジェクトごとに起動する代わりにするため。

#### FR-001: プロジェクト登録(元ID FR-P01 / Must / MS: M2)
- **概要**: フォルダを選んで(ダイアログ/Finder からドロップ)プロジェクトとして登録できる。
- **受け入れ基準**:
  - [ ] (派生)フォルダ選択ダイアログでフォルダを選ぶと、そのフォルダをルートとするカードが 1 枚追加されること
  - [ ] (派生)Finder からフォルダをドロップすると、同様にカードが 1 枚追加されること
  - [ ] (派生)登録によって、プロジェクトのフォルダ内に Arin のファイルが作成されないこと(REQ §4.1)
- **データモデル変更**: Project を追加

#### FR-002: プロジェクト切替(元ID FR-P02 / Must / MS: M2)
- **概要**: 一覧から選択すると、ツリーとターミナルが同時にそのプロジェクトへ切り替わる。
- **受け入れ基準**:
  - [ ] (原AC-P02)A・B が登録済みで A を表示中に一覧で B をクリックしたとき、ツリーのルートが B のルートになり、ターミナル領域に B のタブ群が表示され、A のプロセスが終了しないこと

#### FR-003: プロジェクト削除(元ID FR-P03 / Must / MS: M2)
- **概要**: プロジェクトを一覧から削除できる。フォルダ実体は消さない。動作中プロセスがあれば確認する。
- **受け入れ基準**:
  - [ ] (派生)削除するとカードが一覧から消え、ルートフォルダとその中身がディスク上に変化なく残ること
  - [ ] (派生)そのプロジェクトに動作中のプロセスがあるとき、削除前に確認が表示され、中止を選ぶと何も変化しないこと

#### FR-004: 起動時の復元(元ID FR-P04 / Must / MS: M2)
- **概要**: 登録プロジェクト・並び順・最後に選択していたプロジェクトを次回起動時に復元する。
- **受け入れ基準**:
  - [ ] (原AC-P04)A・B・C を登録し B を選択した状態でアプリを終了して再起動したとき、同じ順で 3 件が並び B が選択されていること

#### FR-005: 並び替え・表示名変更(元ID FR-P05 / Should / MS: M6)
- **概要**: カードのドラッグによる並び替えと、表示名の変更ができる。
- **受け入れ基準**:
  - [ ] (派生)カードをドラッグして順序を変えると一覧の順が変わり、再起動後も同じ順であること
  - [ ] (派生)表示名を変更するとカードの名前が変わり、ルートフォルダの名前は変化しないこと

#### FR-006: ショートカットでの切替(元ID FR-P06 / Should / MS: M6)
- **受け入れ基準**:
  - [ ] (派生)`⌘1`〜`⌘9` を押すと、一覧の 1〜9 番目のプロジェクトが選択されること

#### FR-007: ルートフォルダへの追従(元ID FR-P07 / Must / MS: M2。C-16 で確定)
- **概要**: ルートフォルダはパスではなく実体で記憶し(macOS のブックマーク)、移動・改名されても自動で追従する。フォルダが削除されて見つからない場合は、カードを「見つからない」表示にして残し、再リンク/一覧から削除を選べる。自動では消さない(C-06 で確定)。
- **受け入れ基準**:
  - [ ] (原AC-P07。表示場所は C-25 で確定)`~/dev/app` を登録済みで Finder で `~/dev/app2` に改名したとき、カードは同じプロジェクトのまま、カードのツールチップのルートパス表示が `~/dev/app2` に変わり、ツリーも表示され続けること
  - [ ] (派生・C-06 で確定)ルートフォルダが削除されたとき、カードが「見つからない」表示で残り、再リンクと一覧からの削除を選べること

#### FR-008: カード形式の一覧(元ID FR-P08 / Must / MS: M2)
- **概要**: プロジェクト一覧はカード形式。カード数が上段の高さを超えたら上段内でスクロールする。カードは 1 行で、表示するのはプロジェクト名・実行中の印・git ブランチ名(C-03 で確定。§6.2)。
- **受け入れ基準**:
  - [ ] (派生)1 プロジェクトにつきカードが 1 枚表示され、選択中のカードが強調表示されること
  - [ ] (派生)カードの合計高さが上段の高さを超えたとき、上段内だけがスクロールし、下段のツリーの位置と高さが変わらないこと

#### FR-064: カードからルートパスをコピー(元IDなし。2026-11-14 の PRD ゲートで本人が追加 / Must / MS: M2)
- **概要**: カードを右クリックしたメニューから、そのプロジェクトのルートの絶対パスをコピーできる。カードにルートパスを常時表示しない(C-03)ことの補い。
- **受け入れ基準**:
  - [ ] (派生)カードを右クリックすると、メニューに「絶対パスをコピー」が表示されること
  - [ ] (派生)ルートが `/Users/me/dev/app` のカードで「絶対パスをコピー」を選ぶと、クリップボードに `/Users/me/dev/app` が入ること
  - [ ] (派生)選択中でないカードを右クリックしてコピーしても、選択中のプロジェクトが切り替わらないこと

#### FR-009: ペイン境界の可変と復元(元ID FR-P09 / Must / MS: M2)
- **概要**: 左ペインの上段(カード)と下段(ツリー)の境界をドラッグして高さ配分を変更でき、次回起動時に復元する。左右ペインの幅も同様。左ペインは折りたたみ可(REQ §5)。
- **受け入れ基準**:
  - [ ] (原AC-P09)上段と下段の境界を下へドラッグして上段を広げた状態でアプリを終了して再起動したとき、同じ高さ配分で表示されること
  - [ ] (原AC-P09)上段・下段とも最小高さを下回らないこと
  - [ ] (派生)左右の境界をドラッグして変えた幅が、再起動後も同じであること
  - [ ] (派生)左ペインを折りたためること

#### FR-010: 二重登録の防止と入れ子の許可(元ID FR-P10 / Must / MS: M2。C-16 で確定)
- **受け入れ基準**:
  - [ ] (原AC-P10)`~/dev/app` を登録済みで同じフォルダを再度登録したとき、カードが増えず既存カードが選択されること
  - [ ] (原AC-P10)`~/dev/app/frontend` を登録したとき、別のカードとして追加されること

#### FR-011: ブランチ名の表示(元ID FR-P12 / Should / MS: M6)
- **概要**: ルートが git リポジトリ(worktree を含む)の場合、カードに現在のブランチ名を表示する。読み取りのみで git 操作はしない(N7)。
- **受け入れ基準**:
  - [ ] (派生)ルートが git リポジトリまたは worktree のとき、カードに現在のブランチ名が表示されること
  - [ ] (派生)ルートが git リポジトリでないとき、ブランチ名が表示されないこと
  - [ ] (派生)ブランチ名の取得によってリポジトリの状態が変化しないこと

#### FR-012: 実行中の印(元ID FR-P13 / Should / MS: M6)
- **概要**: そのプロジェクトのいずれかのターミナルで、シェル以外のプロセスが前面で動いている間だけ、カードに「実行中」の印を出す。
- **受け入れ基準**:
  - [ ] (派生)プロジェクトのターミナルでシェル以外のプロセスが前面で動いているとき、カードに印が表示されること
  - [ ] (派生)そのプロセスが終了してシェルに戻ったとき、印が消えること

### 3.2 ファイルツリー

ユーザーストーリー: 本人が、プロジェクトのファイル構成を見て、ファイルパスを最短手数でターミナル(AI エージェントへの入力)に渡したい(G3)。

#### FR-013: 階層表示と遅延読み込み(元ID FR-T01 / Must / MS: M3)
- **受け入れ基準**:
  - [ ] (派生)プロジェクトルートを起点に、フォルダとファイルが階層表示されること
  - [ ] (派生)フォルダの中身は、そのフォルダを展開したときに読み込まれること

#### FR-014: 変更の自動反映(元ID FR-T02 / Must / MS: M3)
- **概要**: ファイルシステムの変更(追加・削除・リネーム)を自動反映する。手動リロード不要。
- **受け入れ基準**:
  - [ ] (原AC-T02)プロジェクト A を表示中で `src` が展開済みのとき、ターミナルで `touch src/new.txt` を実行すると、2 秒以内に `src` 配下へ `new.txt` が現れること
  - [ ] (派生)外部での削除・リネームも、手動操作なしでツリーに反映されること

#### FR-015: パスのコピー(元ID FR-T03 / Must / MS: M3)
- **概要**: 相対パス(ルート基準)/絶対パスをコピーできる。コンテキストメニューとショートカットの両方。
- **受け入れ基準**:
  - [ ] (原AC-T03)ルート `/Users/x/dev/app` の `src/a b.ts` を選択して相対パスコピーしたとき、クリップボードが `src/a b.ts` であること
  - [ ] (派生)同じ対象で絶対パスコピーしたとき、クリップボードが `/Users/x/dev/app/src/a b.ts` であること

#### FR-016: ターミナルへのドラッグ挿入(元ID FR-T04 / Must / MS: M3)
- **受け入れ基準**:
  - [ ] (原AC-T04)ルート `/Users/x/dev/app` の `src/a b.ts` をターミナルへドラッグしたとき、入力行に `src/a\ b.ts`(末尾に半角スペース)が挿入され、Enter が送られないこと

#### FR-017: 隠しファイル表示の切替と既定の除外(元ID FR-T05 / Must / MS: M3)
- **概要**: 隠しファイル表示を切り替えられる。既定の除外対象は `.git` `node_modules` `.DS_Store` の 3 つに限定する(C-07 で確定)。
- **受け入れ基準**:
  - [ ] (派生)切替操作で、隠しファイルの表示/非表示が切り替わること
  - [ ] (派生・C-07 で確定)既定の状態で `.git` `node_modules` `.DS_Store` がツリーに表示されないこと

#### FR-018: Finder で表示/既定アプリで開く(元ID FR-T06 / Must、Quick Look 部分のみ Should / MS: M3、Quick Look は M6)
- **受け入れ基準**:
  - [ ] (派生)「Finder で表示」で、Finder が対象を選択した状態で開くこと
  - [ ] (派生)「開く」またはダブルクリックで、ファイルが拡張子に対応した既定アプリで開くこと
  - [ ] (派生・Should)スペースキーで Quick Look が表示されること

#### FR-019: フォルダから新規ターミナルタブ(元ID FR-T07 / Should / MS: M6)
- **受け入れ基準**:
  - [ ] (派生)フォルダを右クリックして「ここでターミナルを開く」を選ぶと、そのフォルダを cwd とする新規タブが、そのプロジェクトに追加されること
