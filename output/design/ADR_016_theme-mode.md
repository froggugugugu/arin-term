# ADR-016: テーマ(システム・ライト・ダーク)を設定画面で選び、アプリの外観で切り替える

- 状態: Accepted(本人が 2026-11-20 に要望を出し、計画を了承した。実機の見た目は本人の確認待ち)
- 日付: 2026-11-21
- 関係: ADR-010(すりガラス)、ADR-013(設定画面)、ADR-014(透過)

## 背景(本人の要望。原文)

「テーマはダーク、ライト、システムは選択できるようにしてほしい。管理画面から。」

これまでは OS の設定に追従するだけだった(`tokens.css` の `prefers-color-scheme`。アプリ独自の切替は無い)。

## 決定

### 1. 切り替えるのは Rust。画面の CSS には切替を書かない

テーマを替えるときは、Rust が macOS のアプリの外観を替える(Tauri の `AppHandle::set_theme`。ライト・ダークは固定、システムは `None` で OS に追従)。
画面(WKWebView)の `prefers-color-scheme` はアプリの外観に追従するので、次のものが今の仕組みのまま一緒に替わる。

- `tokens.css` の 2 つの media query(色のトークン)
- ターミナル(xterm.js)とエディタ(CodeMirror)。どちらも CSS の変数で色を取る
- 透過(`applyTranslucency.ts` はライト用・ダーク用の両方を `:root` に当ててあり、media query が使い分ける)
- ウィンドウのすりガラス(ADR-010)とメニュー

画面のソースに `matchMedia` は無く、JS の側の追従は要らない。

### 2. 値は `state.json` の `ui.theme`

| 値 | 意味 |
| -- | ---- |
| (キーなし) | システム(OS の設定に追従)。既定 |
| `"light"` | いつもライト |
| `"dark"` | いつもダーク |

- システムのあいだは書かない。知らない値・文字列でない値は、`state.json` を退避せずにシステムにする。`schemaVersion` は 1 のまま
- 型は `arin_core::layout::theme::ThemeMode { System, Light, Dark }`。`Workspace::set_theme(mode) -> bool`(変わったら真)。写しに `theme` を足す(項目の追加なので写しの版は上げない)
- コマンドは `set_theme({ theme })`。変わったときだけ写しを送り(保存が予約される)、アプリの外観に当てる。起動時は setup の中で保存値を当てる(画面が描かれる前)
- 設定画面の「既定に戻す」(`reset_appearance`)はテーマを変えない。数値の調整(文字の大きさ・透過)を戻すボタンで、選んだテーマまでは戻さない(Vim の切替と同じ扱い)

### 3. 外観へ当てる処理は差し替えられる口にする(`ThemeApplier`)

模擬ランタイム(`src-tauri/tests/`)は外観の切替を実装しておらず、呼ぶと panic する(`tauri::test::mock_runtime` の `set_theme` は `unimplemented!`)。
そこで、当てる処理を `ThemeApplier`(管理下の状態)に入れておき、本物のランタイムで起動したときだけ `run` が中身を入れる。入っていなければ何もしない。
テストは記録するだけの中身を入れて、「変わったときだけ当てる」ことを確かめる。

### 4. 設定画面

「透過」の組を「外観」に改め、いちばん上に「テーマ」の行を足す(システム・ライト・ダークの 3 つ並びの切替。`role="radiogroup"`)。
透過の 2 行の名前は「ウィンドウの透過」「ターミナルの背景の透過」にする。組を増やさなかったのは、高さ 600 の画面でシートが縦にはみ出すため。
3 つ並びの切替は、エディタの表示の切替(ADR-015 の 8)と同じ部品 `SegmentedRadio` にまとめた。

## 却下した案

- **`:root` に `data-theme` を付けて CSS で分ける**: media query 2 か所と透過の当て方を書き直すことになる。すりガラスとメニューは OS の外観のまま残り、画面の色と食い違う
- **`settings.toml` に書く**: 設定ファイルは `[shortcuts]` だけを読む(ADR-012)。設定画面で選ぶ値は `state.json` に置く(ADR-013・ADR-014 と同じ)

## 確かめたこと(2026-11-21。デバッグ版の `.app`、OS はダーク)

`ui.theme` を置いた状態フォルダで起動し、画面の `matchMedia("(prefers-color-scheme: dark)")` の結果を一時的な確認用の行で標準エラーに出した(確認後に外した)。

| `ui.theme` | 画面の判定 |
| ---------- | ---------- |
| `"light"` | ライト(`dark=false`) |
| `"dark"` | ダーク(`dark=true`) |
| (キーなし) | ダーク(OS に追従) |

## 残っている確認(本人)

- 設定画面で切り替えたとき、サイドバー・ターミナル・エディタ・すりガラス・メニューが一緒に替わる見た目(画面の撮影は権限が無く AI は見ていない)
- 「システム」のまま OS の外観を替えたときの追従
