# ADR-020: ターミナルの選択を真ん中クリックで貼り付け、右クリックのメニューでコピー・ペーストする

- 状態: Accepted(本人が 2026-11-28 に方式と既定を選んだ。実機の手触りは本人の確認待ち)
- 日付: 2026-11-28
- 関係: FR-043(コピー・ペースト)、設計書 §9.1、ADR-013(設定画面)、ADR-019(右クリックのメニュー)

## 背景(本人の要望と回答。原文)

「ターミナルで、可能であれば選択部分のコピーと真ん中のマウスクリックで貼り付けとかできる？」

- 方式: 「最初からONにして、その方針でOK.」(提示した 2 案のうち、推奨の「アプリの中だけに持つ」)
- 追加: 「右クリックでのコピ、貼り付けもできるといいな。」

## 決定

### 1. 選択は アプリの中の入れ物に持つ(X11 の PRIMARY と同じ考え方)

- ターミナルで文字を選ぶと、その文字列をアプリの中に 1 つだけ持つ(`TerminalManager`。全ターミナルで共通。最後に選んだもの)
- システムのクリップボード(⌘C・⌘V)には書かない。選ぶだけでクリップボードの中身は変わらない
- 選択を外しても持った文字列は消さない(次に選ぶまで残す)。アプリを終えると消える(保存しない)
- 真ん中クリックで、クリックしたターミナルにその文字列を貼る(⌘V と同じ `paste`。改行の CR へのそろえとブラケットペーストは xterm.js)。
  貼る前にそのターミナルへフォーカスを移す。持っている文字列が無ければ何もしない

### 2. マウスを使うアプリが動いているあいだはアプリに渡す

- xterm.js のマウスの報告のモード(vim の `mouse=a`、htop など)が有効なあいだは、真ん中クリックと右クリックをアプリに渡し、Arin は何もしない
- Option を押しながらなら Arin が受ける(Option を押しながらのドラッグで選べる `macOptionClickForcesSelection` と同じ考え方)
- 判定は `src/logic/terminal/mouseRouting.ts`(純粋)

### 3. 右クリックのメニュー

- 項目は「コピー」「ペースト」、区切り、「すべてを選択」。選択が無ければ「コピー」は薄くする
- 右クリックで選択の外を押すと、xterm.js が単語を選ぶ(`rightClickSelectsWord`。macOS のターミナルと同じ)。選択の中を押せば選択はそのまま
- 「コピー」はシステムのクリップボードに書く(`write_clipboard_text`)。「ペースト」はシステムのクリップボードを読んで貼る(`read_clipboard_text`)。
  画面からは `copy`・`paste` のイベントを起こせず、WebKit の `navigator.clipboard` は確認を出すので、Rust の `PasteboardPort` を通す
- 読むのはプレーンテキストだけ。文字列が無ければ何もしない

### 4. 設定

- 設定画面に「選択して真ん中クリックで貼り付け」の切替を置く。既定は ON
- `state.json` の `ui.middleClickPaste`(偽のときだけ書く。無い・真偽値でなければ真)。写しの `middleClickPaste`、コマンド `set_middle_click_paste`
- OFF のあいだは選択を持たず(持っていたものも捨てる)、真ん中クリックはそのまま xterm.js に渡す。右クリックのメニューは設定に関係なく出す
- 「既定に戻す」(見た目の数値)はこれを変えない

## 却下した案

| 案 | 理由 |
| -- | ---- |
| 選択をシステムのクリップボードに書く(iTerm2 の「選択でコピー」) | 本人が推奨の「アプリの中だけ」を選んだ。選ぶたびにクリップボードが上書きされる |
| マウスを使うアプリが動いていても右クリックで必ずメニューを出す | 真ん中クリックと規則がそろわず、アプリに右クリックが届かなくなる。Option で出せる |
| 画面から `navigator.clipboard` で読み書きする | WKWebView で確認が出る・許可されないことがある。Rust にすでに `NSPasteboard` の口がある |

## 影響

- `PasteboardPort` に `read_text` を足す(画面の求めでクリップボードの文字列を読む口ができる。読むのは本人が「ペースト」を選んだときだけ)
- `TerminalSurface` に `onSelectionChange`・`appOwnsMouse` を足す
